## Unix

**Entstehung:** 1969, Bell Labs (AT&T)
**Merkmale:** Multi-User, Multi-Process, Netzwerkfähig

**Anwendungsfälle (Prüfung: 3 nennen):**
1. Server / Cloud
2. Finanzwesen / Banken
3. Telekommunikation / Wissenschaft

**Beispiele (Prüfung: 2 nennen):** macOS · FreeBSD
*(weitere: iOS, NetBSD)*

---

## Linux

**Ersteller:** Linus Torvalds (GNU/Linux)
**Merkmale:** Frei, Open Source, als "Distributionen" (Distros) verteilt

**Anwendungsfälle (Prüfung: 3 nennen):**
1. Server (Web, Datenbank, Cloud)
2. Smartphones (Android = Linux-Kern)
3. Supercomputer (Top 19 laufen auf Linux)
*(weiterer: Netzwerkgeräte / Industrie)*

**Beispiele (Prüfung: 2 nennen):** Debian · Ubuntu
*(weitere: Manjaro, Gentoo, Rocky Linux)*

---

## Windows

**Hersteller:** Microsoft
**Aktuell:** Windows 11 (Oktober 2021)
**Marktanteil Desktop:** ~51%
**Merkmale:** Proprietär, kostenpflichtig, weit verbreitet auf PCs

**Anwendungsfälle (Prüfung: 3 nennen):**
1. Office / Business PCs
2. Gaming
3. Embedded Systems / Medizingeräte
*(weiterer: Virtualisierung / Cloud Azure)*

**Beispiele (Prüfung: 2 nennen):** Windows 11 · Windows Server
*(weitere: Windows 10, Xbox)*

---

## Merksatz

> **Unix** = ursprünglich, macOS/FreeBSD
> **Linux** = Open Source, kostenlos, Server/Supercomputer
> **Windows** = proprietär, kostenpflichtig, PCs/Gaming
