## Interne Hardware

| Komponente | Funktion |
|-----------|----------|
| **CPU** | Führt Befehle aus (Prozessor) |
| **RAM** | Temporärer Arbeitsspeicher (flüchtig) |
| **HDD** | Langsam, günstig, permanent |
| **SSD** | Schnell, teuer, permanent |
| **GPU** | Grafik/Bildberechnung |
| **PSU** | Netzteil – Stromversorgung |

## Software

- **Software** = alle Computerdaten (Programme, Dateien, OS)
- **Anwendung** = Software für eine bestimmte Aufgabe (immer ausführbar, nutzerorientiert)
- **Betriebssystem** = Schnittstelle zwischen Hardware und Software

> Das OS abstrahiert die Hardware und verwaltet Ressourcen.
