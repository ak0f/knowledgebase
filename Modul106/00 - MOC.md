## Lernziele Übersicht (alle Module)

- [ ] Zahlen-, Text- und Date/Time-Datentypen korrekt einsetzen
- [ ] Passwort verschlüsselt ablegen (`SHA2`)
- [ ] Tabellenstruktur mit `ALTER TABLE` verändern
- [ ] Tabellen und Datenbanken mit `DROP` löschen
- [ ] Daten mit `UPDATE` / `DELETE` verändern und löschen
- [ ] Daten mit `SELECT`, `WHERE`, `ORDER BY` gefiltert und sortiert auslesen
- [ ] Datenbank als Dump File exportieren/importieren
- [ ] Daten aus CSV mit `LOAD DATA INFILE` importieren
- [ ] Fremdschlüsselprüfung für Migration aus-/einschalten
- [ ] Datenschutzgrundlagen nennen (BV Art. 13, DSG Art. 7 und 3c)
- [ ] Datenbankbenutzer erstellen (`CREATE USER`) und löschen (`DROP USER`)
- [ ] Rechte vergeben/entziehen (`GRANT` / `REVOKE`) auf DB- und Tabellenebene
- [ ] Tabellen mit `JOIN`, `LEFT JOIN`, `RIGHT JOIN` verknüpfen
- [ ] Mit `LIKE`, `BETWEEN`, `IN`/`NOT IN` filtern
- [ ] Aggregatfunktionen mit `GROUP BY` / `HAVING` einsetzen
- [ ] Transaktionen mit `START TRANSACTION`, `COMMIT`, `ROLLBACK` steuern
- [ ] ACID-Kriterien erklären (Atomic, Consistent, Isolated, Durable)
- [ ] Performancerelevante Faktoren nennen und mit `EXPLAIN` analysieren
- [ ] Abfragen mit Indizes (`ALTER TABLE ... ADD INDEX`) optimieren
